# Disease Prediction System

A machine learning-based web application that predicts possible diseases from selected symptoms using Streamlit and Scikit-learn.

## Features

- Symptom-based disease prediction
- Multiple symptom selection
- Confidence score
- Severity detection
- Recommendations/precautions
- Interactive Streamlit UI

## Technologies Used

- Python
- Streamlit
- Scikit-learn
- Pandas
- Pickle

## Machine Learning Model

- Decision Tree Classifier

## Symptoms Included

- Fever
- Cough
- Headache
- Fatigue
- Body Pain
- Sore Throat
- Nausea
- Vomiting
- Cold
- Dizziness

## Diseases Predicted

- Flu
- Cold
- Migraine
- Viral Fever
- Allergy
- Food Poisoning
- Typhoid
- Sinus
